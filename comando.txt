======================================================================
     GUIA DE COMANDOS - SISTEMA DE LOCAÇÃO (BACKEND)
======================================================================

--- 1. AMBIENTE VIRTUAL (VENV) ---

python -m venv venv
-> Cria a pasta isolada (ambiente virtual) onde as bibliotecas do projeto serão instaladas.

.\venv\Scripts\activate
-> (Apenas no Windows) Ativa o ambiente virtual para o terminal começar a usar o Python do projeto.


--- 2. GERENCIAMENTO DE BIBLIOTECAS (DEPENDÊNCIAS) ---

pip freeze > requirements.txt
-> Salva a lista com os nomes e versões de todas as bibliotecas instaladas no projeto dentro de um arquivo de texto.

pip install -r requirements.txt
-> Lê o arquivo "requirements.txt" e instala todas as bibliotecas listadas nele de uma vez só.


--- 3. BANCO DE DADOS E MIGRAÇÕES (FLASK-MIGRATE) ---

flask db init
-> Inicializa o sistema de controle de versões do banco de dados (Alembic). Cria a pasta "migrations". Só deve ser rodado uma vez na criação do projeto.

flask db migrate -m "mensagem"
-> Compara as classes do Python com o banco de dados e gera um arquivo de "receita" (migração) com o que precisa ser criado ou alterado.

flask db upgrade
-> Aplica as receitas pendentes no banco de dados, criando ou atualizando as tabelas físicas lá no PostgreSQL de fato.


--- 4. CONFIGURAÇÃO (.env) ---

copy .env.example .env
-> Cria o arquivo .env local (ele NÃO vai para o git). Preencha DATABASE_URL e SECRET_KEY.

flask --app main criar-admin
-> Cria o primeiro usuário administrador (pede nome, e-mail e senha).


--- 5. EXECUÇÃO ---

python main.py
-> Liga o servidor backend (API em http://localhost:5000). Aplica as migrations automaticamente.

$env:API_BASE="http://localhost:5000"; python app/views/gui_flet.py
-> Liga a interface web (Flet) em http://localhost:8000, apontando para o backend local.
   Sem API_BASE, o frontend usa o backend hospedado no Render.

python -m pytest
-> Roda os testes automatizados.


--- 6. DEPLOY NO RENDER ---

O arquivo render.yaml descreve os dois serviços (API Flask + frontend Flet).
Render > New > Blueprint > escolha o repositório, e preencha:
  - arena-facil-api: DATABASE_URL (PostgreSQL, ex.: Supabase)
  - arena-facil-web: API_BASE = URL pública da API (ex.: https://arena-facil-api.onrender.com)
No plano free os serviços "dormem" após 15 min sem uso; o primeiro acesso leva ~1 min.
